# ONE Companion Plugin

A WordPress companion plugin for ONE care operations. This initial foundation intentionally prioritizes bootstrap wiring, activation, database installation, roles, capabilities, documentation, and audit logging before any sensitive operational modules are built.

## Current scope

- Main plugin bootstrap file.
- Activation and database installation logic.
- Role and capability model.
- Audit log database table.
- Production documentation checklist.

## Security-first development order

Time clock, client records, transportation, and other sensitive employment or client-service modules must not be implemented until the security model, permissions, database schema, and audit logging are reviewed and approved.
